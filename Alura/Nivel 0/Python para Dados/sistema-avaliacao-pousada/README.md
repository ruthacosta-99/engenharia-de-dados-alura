# 🏨 Sistema de Avaliação de Pousada

Projeto desenvolvido durante meus estudos de **Python para Dados**, com o objetivo de aplicar os fundamentos da linguagem em um exercício prático e integrado.

A proposta foi reunir diferentes conceitos estudados em um único programa, simulando o registro e a avaliação de uma estadia em uma pousada.

## 💻 Funcionalidades

O programa permite:

- Registrar nome, idade e altura do hóspede;
- Informar quantidade de pessoas e dias de estadia;
- Calcular o valor total da hospedagem;
- Calcular valores por pessoa e por diária;
- Utilizar divisão inteira e resto da divisão;
- Registrar notas para limpeza, conforto e atendimento;
- Calcular média simples e média ponderada das avaliações;
- Manipular o comentário deixado pelo hóspede;
- Exibir um resumo completo da estadia.

## 🧠 Conceitos praticados

Durante o desenvolvimento foram utilizados:

- Variáveis;
- Entrada de dados com `input()`;
- Conversão de tipos com `int()` e `float()`;
- Strings;
- Operadores aritméticos;
- Divisão inteira e módulo;
- Exponenciação;
- Média simples e ponderada;
- F-strings;
- Formatação de números;
- Métodos de strings, como `upper()`, `lower()`, `strip()` e `replace()`.

## 🛠️ Tecnologia

- Python
