# 📊 Engenharia de Dados — Alura

Este repositório reúne meus **estudos, exercícios e desafios práticos** desenvolvidos ao longo da formação em **Engenharia de Dados da Alura**.

O objetivo é registrar minha evolução na área, aplicando os conceitos estudados em exercícios e pequenas aplicações ao longo da formação.

## 🎯 Objetivo

Construir uma base sólida em Engenharia de Dados, evoluindo dos fundamentos de **Python, SQL e computação em nuvem** até o desenvolvimento de pipelines e o estudo de arquiteturas e ferramentas utilizadas na área.

Este repositório será atualizado conforme avanço na formação.

---

## 📚 Estrutura da formação
